HOW TO UPDATE THIS SITE  (Mrs. Tesnar's 5th Grade Math & Science)
==============================================================

Every page is a plain .html file. Open one on GitHub, click the pencil
(Edit), change the words, and click "Commit changes". The website updates
in about 2 minutes.

CHANGE THE NAME AT THE TOP OF EVERY PAGE
  site-bar.js  →  near the top:  var NAME = "Mrs. Tesnar", SUBJECT = "5th Grade";
  The page titles and footers say "Mrs. Tesnar's 5th Grade".

CHANGE THE TOP-BAR LINKS
  site-bar.js  →  the LINKS list right under NAME.

PAGES
  index.html               Home page
  math/index.html          Math year at a glance (units, dates, NC standards)
  math/unit1.html …        One page per math unit: targets, standards, vocabulary, notes/homework links, practice
  science/index.html       Science year at a glance (units, pacing, NC science standards)
  science/unit1.html …     One page per science unit: phenomenon, standards, words to know, notebook, labs
  fluency-lab/             Fluency Lab: 10 modules, each with leveled Practice and a Skill Check
  learning-lab/            Fluency practice (facts, multi-digit, decimals, fractions, order of operations, volume)
  arcade/                  Math games
  lab/                     Virtual science lab activities
  notes/                   Interactive science notebooks with practice
  practice/                Extra math practice for each unit (Illustrative Math style)
  vocabulary.html          Math and science words with definitions
  formulas.html            Formula and equation sheet
  class-information.html   Welcome, how we learn, schedule, supplies, grading, contact
  resources.html           Helpful links

LESSON PAGES (one page per lesson)
  Every lesson has its own page, like math/unit0/lesson-1.html or science/unit0/lesson-3.html.
  Each page has: Goals (I can + NC standards), Outline + Materials, Interactive Notes,
  Practice, a Lab, and an Exit Ticket (students see their score at the end).

  The WORDS for every lesson in a unit live in ONE file:
    lessons/data/math-u0.js       Math: Launching the Year
    lessons/data/science-u0.js    Science: Unit 0
  Open the file, find the lesson ("n: 2," is Lesson 2), and change the words inside the quotes.
  Keep the quotes, commas and brackets.

  ADD A LINK TO A MATERIAL (slides, handout, Google Doc)
    In the lesson's materials list, change   'Student handout'
    to   { t: 'Student handout', href: 'PASTE THE SHARE LINK HERE' }
    (Google Doc: Share → "Anyone with the link" → Copy link.)

  Student work (notes, sketches, scores) saves only on that student's device. Nothing is sent.
  The unit page shows the list of lessons automatically.

ADD YOUR LESSON NOTES OR HOMEWORK TO A UNIT
  Open math/unit1.html (or any unit). Find the rows that say "Lesson notes" and "Homework".
  Replace href="#" with the link to the Google Doc, PDF or IM student page.

ADD A UNIT PAGE
  1. Open math/unit1.html → copy everything.
  2. Add file → Create new file → name it math/unit2.html → paste → edit the words.
  3. In math/index.html, change that unit card's href="#" to href="unit2.html".

ADD A LINK TO A PDF OR GOOGLE DOC
  In a unit page, each row looks like:
    <a href="#" class="feature-card"> … </a>
  Replace # with the link (for a Google Doc: Share → "Anyone with the link" → Copy link).
  To post a PDF: Add file → Upload files, then link to it, e.g. href="files/lesson1.pdf".
